# Практическая работа №3

## Тема
Двумерные матрицы: транспонирование и поиск седловых точек.

## Цель работы
Изучить принципы работы с двумерными массивами в C# и научиться выполнять операции над матрицами.

## Задания
1. Реализовать транспонирование квадратной матрицы без создания дополнительной матрицы.
2. Разработать алгоритм поиска седловых точек.
3. Вывести исходную и транспонированную матрицы.
4. Проверить корректность работы алгоритмов.

## Используемые технологии
- C#
- .NET 8
- GitHub

## Результаты
Программа выполняет транспонирование матрицы и поиск седловых точек.

## Вывод
В ходе практической работы были изучены двумерные массивы и реализованы алгоритмы обработки матриц на языке C#.
